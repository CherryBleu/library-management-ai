# 测试计划

## 环境与追踪

Java 17 兼容编译；mvn test。领域单元测试不启用数据库；集成测试使用 SpringBootTest、MockMvc、独立 H2 内存库。测试固定 Clock，数据每例清理重建，禁止依赖实际日期和测试顺序。下列步骤同时定义验收标准；每例验证错误码及数据库没有部分更新。TC-034/035 为单元/静态架构检查，其余为应用或HTTP集成测试。
